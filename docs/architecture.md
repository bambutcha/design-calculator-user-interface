# Архитектура NovaCalc

## Карта модулей

- `src/App.tsx` — основной интерфейс: ввод, кнопки, история, взаимодействия.
- `src/utils/calculator.ts` — детерминированный парсер и вычислитель выражений.
- `src/utils/cn.ts` — утилита объединения CSS-классов.
- `src/ErrorBoundary.tsx` — защитный контур интерфейса с безопасным восстановлением.
- `electron/main.cjs` — desktop-оболочка и жизненный цикл окна.

## Поток данных

1. Пользователь вводит выражение в `App.tsx`.
2. `handleCalculate()` передает строку в `CalculatorEngine.evaluate()`.
3. Парсер токенизирует, валидирует и вычисляет выражение.
4. Результат и история сохраняются в состояние React и `localStorage`.
5. При сбое интерфейса `ErrorBoundary` показывает экран восстановления.

## Ключевые технические решения

- `eval` не используется: вычисления идут через собственный парсер.
- Процентный режим реализован на уровне парсера (логика “калькуляторных процентов”).
- Сессия сохраняется в `localStorage` (выражение, результат, история, тема).
- `ErrorBoundary` обеспечивает мягкое восстановление после UI-ошибок.
- Electron используется как desktop-оболочка; бизнес-логика изолирована во frontend.
