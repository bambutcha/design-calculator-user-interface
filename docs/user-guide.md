# Руководство пользователя NovaCalc

## Базовые операции

- Поддерживаемые операторы: `+`, `-`, `*`, `/`, `**`, `%`
- Скобки: `(` и `)`
- Функции: `abs(x)`, `sqrt(x)`, `pow(x,y)`, `mod(a,b)`

## Процентный режим

- `10%` -> `0.1`
- `200+10%` -> `220`
- `200-10%` -> `180`
- `200*10%` -> `20`
- `200/10%` -> `2000`

## Управление

- Кнопка `=` или клавиша `Enter` — вычислить выражение
- `CLEAR` или `Esc` — очистить выражение и результат
- Кнопка `Delete` — удалить последний символ
- `History` — открыть/закрыть оверлей истории
- Клик по элементу истории — восстановить выражение

## Сообщения об ошибках

- `Division by zero` — деление на ноль
- `Invalid token...` — недопустимый символ во входе
- `Function '...' is not supported` — функция не поддерживается

## Восстановление сессии

- Приложение сохраняет в `localStorage`:
  - текущее выражение,
  - последний результат,
  - статус,
  - историю,
  - выбранную тему.
- При повторном запуске состояние восстанавливается автоматически.
