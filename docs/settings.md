# Настройки системы NovaCalc

## Пользовательские настройки

- `calc_theme` — тема интерфейса (`light` или `dark`).
- `calc_history` — история вычислений (массив записей).
- `calc_expression` — текущее выражение в поле ввода.
- `calc_result` — последнее отображаемое значение результата.
- `calc_status` — строка состояния интерфейса.

Все значения сохраняются в `localStorage`.

## Поведение настроек

- При старте приложения настройки автоматически читаются и применяются.
- При изменении данных значение сразу синхронизируется в `localStorage`.
- Очистка истории удаляет только `calc_history`, остальные настройки сохраняются.

## Ограничения и границы

- Размер истории ограничен в логике интерфейса (срез последних элементов).
- Настройки локальны для текущего устройства/профиля браузера (или webview Electron).
