# Оценка по критериям (Лабораторная работа №3)

Шкала:
- `1.0` — критерий полностью выполнен
- `0.5` — критерий выполнен частично
- `0.0` — критерий не реализован / не подтвержден

## Итог

Критерии по валидации, вычислениям, UX и восстановлению пользовательской сессии закрыты.  
Незакрытыми остаются только критерии, требующие отдельной подсистемы отказоустойчивости на уровне оборудования и управления конкурирующими процессами (`H0203`, `H0301`).
